Module map (C++ codebase)

  • Vector: core element-wise ops in src/core/Vector.cpp
  • Matrix: linear algebra in src/core/Matrix.cpp
  • Splitter: dataset split abstraction
  • LogisticRegression: train, predict, metrics
  • CSVReader: readCSV and preprocess
  • Logger: timestamped files under logs/
  • ArgParser: --help --train --predict entry

Invalid argv[1] throws runtime_error Unknown option (see ArgParser::run).
